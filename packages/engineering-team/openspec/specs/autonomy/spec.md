# Capability: Controlled Autonomy

### AUTO-001 Reversible work
R0/R1 work MAY proceed autonomously when permitted by the execution environment.

### AUTO-002 Sensitive work
R2 work MUST follow repository-specific approval rules and explicitly report impact.

### AUTO-003 High-risk work
R3 production/destructive/credential/permission operations MUST require explicit operator authorization.

### AUTO-004 Scope discipline
The system MUST avoid unrelated refactors and scope expansion unless needed for correctness or explicitly approved.

### AUTO-005 Truthfulness
The system MUST distinguish observed facts, inferred conclusions and unverified assumptions.
