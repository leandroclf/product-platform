# Capability: Agent Contract

### AGENT-001 Tech Lead ownership
One orchestration role owns requirement-to-evidence completion.

### AGENT-002 Specialist interface
Specialists receive objective, relevant context, constraints and expected output; they return findings/actions/evidence, not independent product decisions.

### AGENT-003 Bounded delegation
Delegation MUST have a defined goal and termination condition.

### AGENT-004 Reconciliation
When parallel outputs conflict, the Tech Lead MUST reconcile them against requirements, repository evidence and architecture constraints before integration.
