# Capability: Portability

### PORT-001 Generic core
Core orchestration MUST remain technology-agnostic.

### PORT-002 Project adapters
Repositories MUST be able to add local commands, architecture, ownership and constraints without modifying generic skills.

### PORT-003 Stack skills
Technology-specific guidance SHOULD be isolated in optional skills.

### PORT-004 Precedence
Nearest project-specific instructions MUST override generic engineering defaults when not conflicting with higher-priority safety constraints.
