# Skill evaluation framework

## Problem
The marketplace can describe and validate skill packages, but it cannot yet measure whether a skill improves outcomes, introduces regressions or uses tools correctly. External agent benchmarks measure different layers and must not be conflated.

## Objectives
Create a benchmark matrix, a versioned internal evaluation contract, deterministic task-suite metadata and minimum metrics for baseline comparison, tool discipline, evidence and regressions. Keep provider execution and external benchmark licenses explicit.

## Scope
Benchmark references, internal task contracts, offline validator, documentation, OpenSpec and CI structural checks. No claim of model performance, no automatic external benchmark download and no paid provider execution in CI.

## Acceptance
The repository describes applicability and limitations of each benchmark, validates benchmark/task/metric metadata, includes a baseline condition in every internal suite and records performance as inconclusive until a real verifier executes.
