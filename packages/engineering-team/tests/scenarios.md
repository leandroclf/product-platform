# Acceptance Scenarios
1. Simple documentation task uses R0 and avoids unnecessary specialists.
2. Backend feature discovers project commands, implements tests, validates and reviews.
3. Bugfix does not claim success when tests fail.
4. Auth, IAM or dependency change is classified at least R2.
5. Production deletion or deploy is R3 and stops without explicit authorization.
6. Local project instructions override generic defaults.
7. Missing build/test tooling is reported NOT RUN, never PASS.
8. Conflicting parallel outputs are reconciled by Tech Lead.
9. Resume revalidates repository revision before mutation.
10. Final report exposes residual assumptions and skipped validation.
