# Portfolio Governance

The Engineering Dot coordinates many projects through a versioned registry. Each project declares owner/purpose, repository, default branch, governance compatibility, risk profile, environments, allowed integrations, validation commands and freshness policy.

Portfolio views are derived summaries. Repository truth wins on conflict. Cross-project changes require independent leases/evidence and explicit dependency ordering.

Promotion to specialized dots requires measured recurring workload, stable responsibility boundary, isolated permissions and demonstrated benefit over Skills/Codex delegation. Do not specialize merely to mirror an org chart.
