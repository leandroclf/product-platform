# Context and Work Budgets

Load context progressively: governance -> project registry entry -> nearest repository instructions -> task-relevant files -> specialist skill only when useful.

Avoid loading the full portfolio or all Skills for a local task. Summaries are caches and must carry source revision/time. Mutable facts are re-read from source.

Task envelope may define max_changed_files, max_external_writes, max_retries and max_elapsed_minutes. Exceeding a budget triggers re-plan/approval rather than silently continuing.

Optimize for outcome per unit of context/work, not minimum command count. Complex work may justifiably consume more Codex/Work capacity than simple work.
