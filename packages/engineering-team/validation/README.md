# Validation Evidence

This directory stores observable validation evidence. Do not store hidden reasoning.

Each run should include scenario ID, timestamp, repository revision, runtime/model identity when observable, prompt, files changed, commands/checks and outcomes, risk classification, approval behavior, final status and evaluator notes.

Allowed status: PASS, FAIL, BLOCKED, INCONCLUSIVE.

Failures are preserved. No missing or unexecuted check is PASS.
