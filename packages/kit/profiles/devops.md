# DevOps Profile

Activate for containers, CI/CD, Kubernetes and cloud infrastructure.

Focus:
- Reproducible builds and immutable artifacts.
- Least-privilege IAM/RBAC.
- Resource limits, probes, rollout/rollback and failure modes.
- Secret management; never commit credentials.
- Environment parity and explicit configuration.
- Validate manifests/plans before applying changes.

Production mutation must be explicit; analysis does not imply permission to deploy.
