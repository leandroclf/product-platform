# Frontend Profile

Activate for web UI work.

Adds:
- `skills/ui/SKILL.md`
- Browser interaction and visual review for every new or materially changed user flow.
- Playwright CLI for responsive, interaction, accessibility and regression checks.

Keep backend/database/infra tooling disabled unless the feature crosses those boundaries.

If the task only changes copy or another non-visual detail, keep verification scoped to that change. If a material UI change cannot be rendered or interacted with in an isolated browser, report the missing evidence as a blocker or limitation; a successful build is not visual acceptance.
